Chart editor: choropleth maps, for parity with Ursula's chart documents. The new `choropleth` type shades the regions of a registered map (`map`, default `europe`) by the first series, in `mapSteps` equal classes (breaks rounded for the legend) or at `mapThresholds`; categories name regions by ISO alpha-3 code or by name, unmatched ones are reported, regions without data are grey, microstates get markers, and the class legend and the map's credit run along the bottom. Without a registered map or any match the chart draws bars and says why. Maps are registered with `registerChartMap` (`getChartMap`, `listChartMaps`, `matchChartMapRegions`, `chartMapBreaks`, `chartMapClass`, `chartMapRamp`); the new `@pixerate/editor/chart-maps` entry point ships `EUROPE_CHART_MAP`, Europe from Natural Earth 1:50m countries (public domain, via world-atlas 2.0.2) in Lambert azimuthal equal-area, generated by `scripts/build-europe-chart-map.mjs`, so the main chart bundle stays free of map data. New agent tool `list_chart_map_regions` and command `chart.mapRegions`; `update_chart` takes `map`, `mapSteps` and `mapThresholds`. The React and Svelte inspectors add Map, Classes and Breaks. Highlight now also dims map regions.
