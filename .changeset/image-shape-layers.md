Add vector shape layers to the image editor. A `ShapeLayer` holds components (live rectangles with corner radii, ellipses, polygons, stars and lines with arrowheads, or free paths) combined with Photoshop's path operations (combine, subtract, intersect, exclude), a fill and a stroke (colour, gradient or pattern; width, alignment, caps, joins, miter limit, dashes). Shapes render without a canvas into the layer's tiles and re-render on every change, so moving and Free Transform map the paths and never degrade them; masks, clipping, blend modes, fill opacity and layer effects work as on pixel layers, and `rasterizeLayer` turns a shape into pixels. New controller methods: `addShapeLayer`, `getShapeLayer`, `setShapeStyle`, `setShapeComponent`, `addShapeComponent`, `removeShapeComponent`, `mergeShapeComponents`; new agent tools: `get_shape_layer`, `add_shape_layer`, `update_shape`, `set_shape_component`, `add_shape_component`, `remove_shape_component`, `merge_shape_components`. Pen, rectangle, ellipse, line and arrow annotations now load as shape layers that render as before; the `annotations` state, the annotation methods and `selectedAnnotationId` keep working on them, and v1 / v2 documents still save back unchanged. PSD export writes shape layers as pixel layers for now.
