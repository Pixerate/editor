Add `@pixerate/editor/paint-editor`, a natural-media paint editor domain built on the shared raster stack and brush engine. `PaintEditorController` holds a canvas (size, dpi), a paper and the shared layer stack, with one undo step per stroke. Papers are generated grain height maps in a library of families (cold and hot pressed, rough, cartridge, laid, charcoal, sanded pastel, canvas, linen, gesso, smooth) with grain depth, scale, tiling and the absorption / permeability / roughness that wet media will use. Built-in dry media (pencils, pastels, charcoal, airbrush, marker, ink and brush pens, erasers, blender, smudge, Mixer Brush) catch the paper's peaks at light pressure and respond to pressure, tilt, barrel rotation and velocity, with separate position and pressure smoothing and fixed / follow-stroke / barrel rotation. The brush library has JSON import / export and thumbnails. Every stroke is recorded as data and can be replayed exactly or varied. Documents save as JSON with PNG assets; exports are PNG, JPEG, WebP and PSD. `createPaintEditorToolProvider` exposes 42 agent tools, and the new `pixerate-paint-editor` skill documents them.
