Vector symbols and instances: `VectorDocument.symbols` and `instance` nodes that draw a symbol through a transform that may scale and skew, Make Symbol, Place, Replace, Detach, per-instance tints and hidden parts, Edit Symbol in isolation mode (the document dimmed behind, undo stepping in and out), SVG `<symbol>` / `<use>` export and import (foreign `<use>` included) and `vector.*Symbol` agent commands. React and Svelte add `VectorSymbolsPanel` and draw isolation mode in the canvas.
