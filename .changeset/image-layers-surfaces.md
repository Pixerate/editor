Image editor: a real layer stack under the hood. Documents are now pixel, adjustment, group and annotation layers on tiled, copy-on-write surfaces (256 px tiles, uniform tiles shared), composited per tile with prefix caches and dirty rectangles. The base sliders become a `develop` filter on the Background layer, blur a `blur` filter, the depth mask a parametric layer mask, and each annotation its own layer; `adjustments`, `depthMask` and `annotations` on the state stay as views, and every existing method keeps working. Undo history stores immutable states that share tiles, bounded by the new `maxHistoryBytes` option. `toJSON()` writes schema v3 (layers, PNG assets) only when a document no longer has the old shape; v1 / v2 documents load, render and save exactly as before (proven by randomised equivalence tests). New: `getLayers`, `getLayer`, `setActiveLayer`, `getLayerPixels`, `getLayerBounds`, `compositePixels`, `migrateToLayeredState`, the `list_layers` agent tool, and a synchronous PNG / zlib codec. `SerializedImageEditorState` is now a union of the v1 / v2 shape (`LegacySerializedImageEditorState`) and v3 (`SerializedLayeredImageEditorState`).
