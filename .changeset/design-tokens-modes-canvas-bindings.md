Add design tokens (Figma-style variables) with modes such as light / dark. The new dependency-free `@pixerate/editor/tokens` subpath has collections, modes (default, add / duplicate / reorder / remove), typed colour / number / string / boolean variables with per-mode values, aliases across collections with cycle and type checks, scopes for pickers, `resolveToken` with diagnostics, an undoable `TokenStore` with change events and transactions, W3C Design Tokens JSON import / export (merging by name, keeping ids, modes in `$extensions`) and CSS custom properties per mode (`exportTokensCss`, `getTokenCssVariables`). Deleting a variable or collection detaches aliases to their values. `@pixerate/editor/canvas` binds node properties (fill, stroke, stroke width, opacity, corner radius, auto layout gap and padding, text colour and size, visibility) to variables via `data.tokenBindings`, with an explicit mode per frame or group (`data.tokenModes`) inherited by descendants; bound values are written into the nodes (`resolveCanvasTokens`), survive copy / paste and duplication, and `detachTokenBindings` keeps the last value when a variable is deleted. React adds the `./tokens` subpath (`useTokens`, `useTokenStore`, `<TokensPanel>`) and `useCanvasTokens`, `<TokenBindingPicker>` and `<TokenModeSwitcher>` in `./canvas`; Svelte adds the same (`createTokens`, `<TokensPanel>`, `createCanvasTokens`, `<TokenBindingPicker>`, `<TokenModeSwitcher>`). Portions ported from FigCraft (MIT OR Apache-2.0).
