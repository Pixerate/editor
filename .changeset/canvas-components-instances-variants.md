Add Figma-style components and instances to the canvas. `@pixerate/editor/canvas` turns a frame (or a wrapped selection) into a main component (`data.component`), places instances (`data.instance`) whose layers are real nodes copied from the main with stable source ids (`data.componentSource`), records edits inside instances as per-layer overrides (`data.componentOverrides`: text, fills, styles, visibility, auto layout padding / gap, token bindings, …) and rebuilds every instance when its main changes, keeping overrides and layer ids (`syncCanvasComponents(before, after)`). Component sets hold variants (`combineCanvasComponentsAsVariants`; switching variants keeps overrides the variants agreed on), and component properties drive layers (boolean → visibility, text → a `data` field, instance swap → a nested instance's main). Also: nested instances, swap, detach (keeps the look), reset overrides (all, per layer or per group), push overrides to the main, a "missing main" state when a main is deleted with `restoreCanvasMainComponent`, cycle prevention, deleting a layer inside an instance hides it, token bindings and per-instance modes inside instances, and links that survive JSON, copy / paste and duplication. `createCanvasComponentsController` makes each action one undoable step with `can…` checks giving disabled reasons; `createComponentCommands` (`@pixerate/editor/commands`) and `createCanvasComponentToolProvider` (`@pixerate/editor/agent`) expose them to the palette and agents. React adds `useCanvasComponents`, `<CanvasComponentsPanel>` and `<CanvasInstanceInspector>`; Svelte adds `createCanvasComponents`, `<CanvasComponentsPanel>` and `<CanvasInstanceInspector>`. Portions ported from FigCraft (MIT OR Apache-2.0).
