Vector constraints: CAD-style geometric constraints and dimensions between anchors, segments and round paths (coincident, collinear, concentric, fix, parallel, perpendicular, horizontal, vertical, tangent, smooth G2, symmetric, equal, distance, angle, radius, diameter) with named parameters and expressions, solved after every edit (edited geometry moving least), conflicts and redundancy refused, degrees of freedom, Auto Constrain, stable anchor ids, canvas glyphs and `vector.*Constraint` agent commands. React and Svelte add `VectorConstraintsPanel`.
