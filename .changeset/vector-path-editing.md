Vector editor: path editing upgrades. Deleting points now keeps the shape (the neighbouring handles are refitted to follow the removed segments as closely as possible; `deleteAnchors(refs, { keepShape: false })` or `setEditing({ keepShapeOnDelete: false })` turns it off). Dragging a segment with the direct tool bends it through the pointer (a click still selects it); `bendSegment(ref, to, t)`. Dragging a lone point can bend its two segments like the Curvature tool (`setEditing({ curvatureMoves: true })`, Alt during the drag flips it; `moveAnchor(ref, to, { curvature })`). New clean-up actions: `joinPaths` (Mod+J), `averageAnchors` (Mod+Alt+J), `removeRedundantPoints`, `smoothPaths` and `cutAtAnchors`. New tools: Scissors (C, cut a path at a point), Knife (K, cut filled shapes along a freehand stroke with no gap between the pieces) and Eraser (E, rub out a round stroke from fills and outlines; `eraserSize`), also as `cutPathAt`, `knife(points)` and `erase(points)`. The pencil gains lazy-mouse smoothing (`pencilSmoothing`) and optional ink-to-shape recognition (`recognizeShapes`: lines, rectangles, ellipses, polygons). Everything edits in each node's own space, so rotated nodes work. New agent commands `vector.deleteAnchors`, `vector.moveAnchor`, `vector.bendSegment`, `vector.join`, `vector.average`, `vector.removeRedundantPoints`, `vector.smooth`, `vector.cut`, `vector.knife`, `vector.erase` and `vector.setEditing`; geometry helpers in `pathEdit` / `pathCut` / `ink` (`removeAnchorKeepingShape`, `bendSegment`, `curvatureMoveAnchor`, `cutSubpathAt`, `joinSubpaths`, `knifePath`, `eraseFromFill`, `LazyMouse`, `recognizeInkShape`, …) and `fitCubicWithTangents` in the curve fitter. The `e` key now picks the eraser (the ellipse tool stays on `o`). Both `VectorCanvas`es draw the knife and eraser strokes, the pencil string and the scissors cut point, and both `VectorToolbar`s add a path-editing group (`showPathEdit`).
