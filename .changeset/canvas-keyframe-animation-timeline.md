Add keyframe animation for canvas nodes. `@pixerate/editor/canvas` stores per-property tracks in `node.data.animation` (so they copy, paste and duplicate with the node) for x, y, width, height, rotation, scale, opacity, fill, stroke, stroke width, corner radius and a motion path. Keyframes use hold, linear, CSS `cubic-bezier` presets or springs; colours interpolate in OKLab with premultiplied alpha; unsorted and duplicate keyframe times are handled. `evaluateAnimation` / `applyAnimation` return evaluated copies without touching the source and compose with `resolveCanvasTokens`. Editing helpers (`setKeyframe`, `updateKeyframe`, `deleteKeyframes`, `setKeyframeEasing`, `setTrackEnabled`, `moveKeyframes`, `scaleKeyframes`, `snapKeyframeDelta`, `copyKeyframes` / `pasteKeyframes`, `recordAnimationChanges`, `animateNode`) never apply partial edits. `AnimationPlayer` plays on an injected `Clock` with loop, ping-pong and playback rate. Export covers `sampleAnimationFrames`, CSS `@keyframes` (`exportCssAnimation`) and Web Animations (`toWebAnimations`). `createCanvasAnimationController` adds record mode, undoable edits and keyframe drags with snapping. `@pixerate/editor/commands` adds `createCanvasAnimationCommands`, which agents can also call as tools (for example `canvas.animation.animateNode`). React adds `useCanvasAnimation` and `<AnimationTimeline>`. Svelte adds `createCanvasAnimation` and `<AnimationTimeline>`. Portions ported from FilmCraft (MIT OR Apache-2.0).
