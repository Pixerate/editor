Two new canvas workflow skills, each with evals: `pixerate-canvas-design-system-components` (main components and linked instances, component sets with named variant properties, overrides) and `pixerate-canvas-layout` (align, distribute, order and lock with the arrange commands). Skill evals can now start from a headless canvas (`CanvasEvalFixture`) with the component, arrange and document tools.
