Two new rich text workflow skills, each with evals: `pixerate-rich-text-report` (one title and a heading hierarchy, lists, tables and charts, a consistency pass) and `pixerate-rich-text-revise` (proofreading, renaming terms with exceptions, tightening, as minimal targeted edits). Skill evals can now start from a rich text document (`RichTextEvalFixture`).
