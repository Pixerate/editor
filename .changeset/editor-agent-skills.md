Ship an Agent Skill per editor domain in `skills/` (rich text, spreadsheet, canvas, vector, chart, diagram, image editor, animation editor, video editor, generation, parameters, plus `pixerate-agent-tools` for what they share). Each `SKILL.md` tells a model when and how to use every tool and command of its domain, with the domain's best practice. A test keeps each skill's tool list in step with the providers.
